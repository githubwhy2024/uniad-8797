# Q5 起始计划

1. 确认实际 8797 设备的 OS、BSP、driver、SDK、工具链、后端和精度。未知值保持 unknown。
2. 从已绑定的逻辑 ONNX 出发，按目标能力选择通用变换与必要兼容适配。CPU 三段、2048 query、18 GiB 和 NHWC 均不作为目标约束。
3. 使用匹配的工具链转换、编译；在工具支持时生成目标 context。记录算子支持、fallback、目标库及 ABI 身份。
4. 实现设备内存注册/同步、资源生命周期、ARM Host 与初始化。保留状态事务、失败关闭和输出所有权。
5. 先验证目标短链及场景切换/恢复，再开展必要任务评测和持续有效新帧的 100 ms/10 Hz 验证。

初始任务只完成共同基线与交付材料。量化、FP16、目标资源参数和精度选择在取得匹配资料与设备表现后另行决定。
